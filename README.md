# FastGood - Site web de restauration rapide

Site vitrine one-page de **FastGood**, entreprise fastfood local.

Interface simple, responsive et claire.

---

## Aperçu

- **Accueil** - Présentation du commerce
- **Menus** - Description des différents menus proposés par le restaurant
- **Contact** - coordonnées

---

## Objectif du client

PixelNova est une agence créative spécialisée dans les sites vitrines modernes et accessibles. Pour lancer un nouveau portfolio de démonstration, l’équipe a besoin d’un environnement Frontend opérationnel et d’une première page (générée via IA) pour itérer rapidement avec les clients.

---

## Instructions d'installation locale

- Installer et ouvrir l'éditeur de code **VSCode**

- Installer l'extension *Live Server*

- Dans le terminal:
```bash
git clone https://github.com/hexadecodeur/carbutarn.git
```
- Ouvrir la page web en local avec le bouton "**Go Live**" en bas à droite
